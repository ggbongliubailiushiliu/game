## 1. 混乱大枪战 · 3D 多人联机射击

▶ **演示视频：[demo-shooter.mp4](demo-shooter.mp4)**（约 4 分钟）

Unity 客户端 + 自研 C# TCP 服务端的第三人称射击 Demo，支持同一房间内多名玩家实时对战。

- **联机对战**：客户端负责输入与表现，服务端负责房间管理、血量与胜负的权威结算；双客户端实测 4–6 人同房。
- **位置同步**：客户端每秒 15 次上传位置与朝向快照，服务端转发给房间内其他玩家，远端做线性插值与球面插值平滑过渡。
- **射击战斗**：动画分层 + 动画遮罩实现边跑边开枪；索敌与翻滚的四方向动作收敛为一个 2D 混合树，参数只喂一个方向向量。
- **子弹对象池**：池内用两张哈希表解决子弹归属问题，避免连发时反复创建销毁带来的 GC 与卡顿。
- **资源热更**：AssetBundle + 服务端版本清单，客户端比对后只下载变化的包，新角色与特效上线无需重打 exe。
- **界面框架**：MVC 分层，UIManager 单例统一负责面板的创建、缓存与开关。
- **选人 / 武器预览**：独立相机渲染到 RenderTexture 再贴到界面，实现 3D 模型实时预览。
- **社交与结算**：世界频道、好友申请与同意、每日签到、战斗结算，均以服务端回包为准刷新。

**技术栈**：C# / Unity / UGUI / Animator / Socket(TCP) / MySQL / MVC / 对象池 / AssetBundle

## 2. 原末鸣初 · 第三人称 ARPG

▶ **演示视频：[demo.mp4](demo.mp4)**（约 4 分钟）

单机第三人称 ARPG，覆盖登录、战斗、任务、背包装备、商店抽奖、小地图的完整流程，可从开头玩到通关。

- **战斗与打击感**：球形范围检测 + 夹角过滤锁定身前扇形敌人；命中由动画事件在指定帧触发，配合伤害飘字。
- **怪物 AI**：有限状态机管理巡逻 / 追击 / 攻击 / 返回 / 死亡五态，工厂模式统一创建，扩展新怪只需加配置与状态。
- **装备与背包**：按部位穿戴并实时重算属性；支持拖拽换位、拖拽绑定快捷栏，药品在快捷栏带冷却遮罩。
- **任务与红点**：任务四态流转，击杀驱动进度并用事件通知界面；红点用"前缀树 + 观察者"逐级汇总。
- **商店与抽奖**：按武器 / 防具 / 鞋子 / 药品分类筛选，批量购买入包；抽奖按权重随机，十连必出保底。
- **界面框架**：单例统一管理面板，面板基类实现"关闭 / 打开中 / 已打开 / 关闭中"四态状态机，路径走 JSON 配置动态加载。
- **寻路与小地图**：NavMesh 寻路并可视化路径点；小地图 / 大地图采用渲染纹理 + 界面控件，支持在大地图上点击寻路。

**技术栈**：C# / Unity / UGUI / Animator / NavMesh / DOTween / JSON 配置驱动
