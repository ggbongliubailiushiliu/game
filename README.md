# 原末鸣初 · 第三人称 ARPG Demo

Unity 独立开发的单机 ARPG 演示，覆盖登录、战斗、任务、背包装备、商店抽奖、小地图等完整流程，可从开头玩到通关。

▶ **演示视频：[demo.mp4](demo.mp4)**（约 4 分钟，1280×720，Unity Editor 内录屏）

## 功能

- **战斗与打击感**：攻击用球形检测 + 夹角过滤锁定身前扇形敌人，伤害由动画帧事件触发并弹出伤害数字。
- **怪物 AI**：有限状态机管理巡逻 / 追击 / 攻击 / 返回 / 死亡五种行为，工厂模式统一生成，扩展新怪只需新增配置与状态。
- **装备与背包**：装备按部位穿戴并实时重算角色属性；背包支持拖拽换位、拖拽绑定快捷栏，药品在快捷栏带冷却遮罩。
- **任务与红点**：任务分未接 / 进行中 / 可提交 / 已提交四种状态，击杀自动推进进度；红点按界面层级逐级汇总。
- **商店与抽奖**：按武器 / 防具 / 药品分类筛选，购买时选数量扣金币入包；抽奖按权重随机，十连必出保底。
- **界面框架与小地图**：面板由单例统一管理，路径走 JSON 配置动态加载；小地图与大地图用 RenderTexture 实时呈现。

## 技术栈

Unity / C# / UGUI / Animator / NavMesh / DOTween / JSON 配置驱动
